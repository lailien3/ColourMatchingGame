# Colour Matching Game!

![logo](src/logo.svg)

## Match your colour block to the randomly generated colour block and get an accuracy score

### Available Scripts

To run the app in development mode :

`npm run start`

To view in browser, open [http://localhost:3333](http://localhost:3333) or run : 

`open http://localhost:3333`

To launch the test runner :

`npm run test`

To build the app for production :

`npm run build`
